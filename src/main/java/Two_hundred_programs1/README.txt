JAVA 200 PROGRAMS - PRACTICE SET

Each program is a separate .java file.
- Every public class name matches its filename.
- No class is named Main.
- Each program has its own main() method.
- Programs use fixed sample values so they can be run immediately.
- You can replace the sample values with Scanner input for interview practice.

Compile one file:
    javac FileName.java

Run:
    java FileName

Examples:
    javac ReverseStringNormal.java
    java ReverseStringNormal

The set contains 200 standalone Java programs covering Strings, numbers,
arrays, patterns, collections, OOP, exceptions, and multithreading.
